# Brand assets

Every file here is generated by `make_brand.py` from her own artwork
(`ui/avatar/flirt.png`) and system fonts (Inter, Noto Serif CJK). Change her art, run the script,
and the whole brand follows — nothing here is hand-edited.

```bash
python3 docs/brand/make_brand.py     # needs pillow + numpy
```

| file | size | where it goes |
|---|---|---|
| `logo.png` | 1024 × 1024 | repository avatar, app icon source |
| `logo-512.png` | 512 × 512 | README header, anywhere a square is needed |
| `banner.png` | 1600 × 600 | the top of the README |
| `social.jpg` | 1280 × 640, 250 KB | GitHub → Settings → Social preview (uploaded by hand: the API cannot set it, and it refuses anything over 1 MB) |
| `signature.png` | 760 × 220, transparent | the foot of the README |
| `screenshot-chat.png` | 584 × 584 | the chat panel, seeded with a demo conversation |

Palette: ink `#0b0f13`, teal `#2ec4b6`, violet `#8b5cf6`. The logo is her eye-line in a badge; the
banner and the social card use the same recipe — her portrait bleeding out of the frame, a blurred
kana watermark, a glass edge, film grain and a hairline frame with teal corner ticks.
