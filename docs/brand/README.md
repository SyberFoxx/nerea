# Brand assets

The logo, the social card and the signature are generated by `make_brand.py` from her own
artwork (`ui/avatar/flirt.png`) and system fonts (Inter, Noto Serif CJK). Change her art, run the
script, and the rest of the brand follows.

**The README banner is the exception**: it is hand art, committed as `banner.png`, and the script
never overwrites it unless you ask.

```bash
python3 docs/brand/make_brand.py            # logo, social card, signature
python3 docs/brand/make_brand.py --banner   # also rebuild the procedural banner
```

| file | size | where it goes |
|---|---|---|
| `logo.png` | 1024 × 1024 | repository avatar, app icon source |
| `logo-512.png` | 512 × 512 | README header, anywhere a square is needed |
| `banner.png` | 1440 × 720, 2:1 | the top of the README — **hand art, not generated** |
| `social.jpg` | 1280 × 640, 252 KB | GitHub → Settings → Social preview (uploaded by hand: the API cannot set it, and it refuses anything over 1 MB) |
| `signature.png` | 760 × 220, transparent | the foot of the README |
| `screenshot-chat.png` | 584 × 584 | the chat panel, seeded with a demo conversation |

Palette: ink `#0b0f13`, teal `#2ec4b6`, violet `#8b5cf6`. The logo is her eye-line in a badge. The
social card keeps the generated recipe — her portrait bleeding out of the frame, a blurred kana
watermark, a glass edge, film grain and a hairline frame with teal corner ticks. The banner follows
the same colours in its own composition, painted at the 2:1 ratio GitHub wants for a social preview.
